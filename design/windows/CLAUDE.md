# Project decisions

- **Duplicate Figma families are intentionally not built.** The Fluent 2 kit repeats 56 component-set names (Avatar/Avatar ×5, .RadioBase ×4, Button ×3, …). Each distinct name is built once, so the "239 of 295 component families" design-system warning is expected. Don't materialize the duplicates.
- **Segoe Sans → Segoe UI.** Segoe Sans is Microsoft's web-only face and can't be obtained for the app. Its `@font-face` in `tokens/fonts.css` points at the installed Segoe UI. Don't ask for Segoe Sans uploads.
- **Segoe font files stay out of this repo.** The repo is public and the fonts' licence text limits them to the Microsoft product they came with. The tokens name the installed Segoe UI Variable families, and `tokens/fonts.css` reaches Segoe UI, Segoe Fluent Icons and Segoe MDL2 Assets with `local()`. Don't add them back to `fonts/`.
- **Accordion carries hand fixes.** `components/content/Accordion.jsx` and its compiled copy in `_ds_bundle.js` make `icon={false}` work in every variant and render `state="disabled"` collapsed, because the kit has no expanded disabled frame. Regenerating the component from Figma, or re-importing the design project without these changes, undoes them.
- **Slate patterns are intentional additions.** `components/patterns/` (PaneSwitcher, PanelToolbar, NoteHeader, EmptyStateLauncher, CountListRow, SettingsLayout, SettingRow) were requested by the user and aren't in the Fluent kit. Ignore the checker's "named after nothing in the kit" warning for them, and keep them listed under Intentional additions in readme.md.
- **WinUI kit: only the listed pieces are built.** From the Windows UI kit, the system builds Checkbox, Radio, MenuItem, MenuMenu, NavNodeMedium and the subtle icon-only Button (rebuilt in place), plus CaptionButton, TabView, ScrollBar and DatePicker. The checker's "3,205 families" warning is expected. Don't import the rest (Windows shell, app icons, repeated sets, controls the Web components cover). Decisions are in winui-review.md.
