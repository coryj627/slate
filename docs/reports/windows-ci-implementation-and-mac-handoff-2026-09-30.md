## Testing-strategy conclusion

Confirmed misalignment lies in avoidable waiting, expensive production queries, missing scheduled Windows stress, incomplete Mac input triggers, weak failure evidence and unproven environment assumptions. Native lifetime, integrity and accessibility obligations remain justified. The local shell failures reinforce the need to distinguish model intent, actual keyboard landing, notification delivery and human AT acceptance.

Keep the full inventory as the reference while reconstructing a small reviewed fault corpus, exploring selected deeper/reordered histories, and evaluating an equivalent source/document-check split. Passing counts, one faster run and pairwise selection alone do not establish equivalent fault detection for a smaller suite.

The preserved `ffb9df3f` app TRX supplies post-repair profiling even though that revision failed its new fixture premise. Summed fact time was 120.822s for GraphDiagramTests (116 facts), 113.647s for CommandPaletteTests (99), 91.737s for GraphNavigatorCensus (26), 59.755s for ReadingFocusTests (253) and 42.734s for ConnectionsLeafCensus (10). The palette scaling fact alone took 97.528s; a symbol-bound GraphNavigator caller-inventory fact took 46.273s. These are profiling leads from one failed-suite execution, not completed-revision latency, stable hardware baselines or evidence that the witnesses are redundant. Machine-readable class/slow-fact summaries are retained beside that TRX.

The next execution experiments therefore have specific targets: profile the palette scaling fixture's GC/finalizer barriers separately from query cost; examine reuse of immutable compiler inputs for the expensive symbol inventories without sharing mutable native sessions; and evaluate a separate source/document target with complete dependency triggers and the same symbol/ancestry enforcement. Preserve graph container/latency bounds while investigating the hosted pilot's slower model throughput; the complete pilot now passes after the scheduling repair. Only an equivalent fault-detection/input contract and measured feedback/billed-unit comparison justify changing cadence, packaging or provider.
