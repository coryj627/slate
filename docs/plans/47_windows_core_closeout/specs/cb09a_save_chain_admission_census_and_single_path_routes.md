- **Rule 1, `EveryVaultSessionMethodTheShellCallsIsClassified`.** Candidates are the invocations and method-group references in `ShellCompilation.Sources` whose simple name is a public instance method of the binding's `VaultSession` (by reflection; `Dispose` left out). Each is bound. A symbol whose containing type is `VaultSession`, or any interface `VaultSession` implements, counts as `VaultSession`'s: the binding declares `IVaultSession`, and a call through it is the same call. Such a candidate must be named in exactly one of the three tables. A candidate that does not bind at all fails. A table name the binding no longer has fails. The message names the file and line and says which table to add the name to. This is the rule that would have caught `ExportSavedQueryAsBase`.
- **How a site is shown admitted.** Build the shell's call graph on demand. A node is a method, constructor or accessor; a lambda or local function belongs to the innermost admission lambda or member that holds it, and an admission lambda is a node of its own. Nodes and edges are keyed by the symbol's `OriginalDefinition`, so a generic method is one node however it is constructed, and a reduced extension call is taken back through `ReducedFrom` to the method it calls. An admission call is a bound call to `WorkspaceSaveCoordinator.Admit` or `Enqueue`, to `INoteSaveChain.Admit`, or to `WorkspaceViewModel.AdmitPropertyWrite`; the argument for its `operation` parameter (`start` for `Enqueue`; never `abandoned`) is an admission lambda. An edge A to B is an invocation of B, or a method-group reference to B, in A's body. The admitted set is the least set that holds every admission lambda and every node that has at least one caller and whose callers are all in the set. A site is admitted when either holds:
  - (A) its node is in the admitted set. A node that implements an interface member, that overrides, or that is virtual or abstract is never admitted by (A): a call through the interface or the base binds to another symbol, so the graph does not hold all of its callers. An admission lambda is admitted whatever holds it; or
  - (B) it sits in an anonymous function assigned to a local, and every read of that local in the member is inside an admission lambda (the property write's shape, `WVM.Properties.cs:427-440`). One read outside an admission lambda, a plain `write(null);` say, and the site is not admitted.
  - If a real joined route fits neither after an honest try, its row may say `ByFact("fact name")`; the census then checks that the fact exists in `SaveChainAdmissionTests`. The PR names every such row. Expected: none.
- **Rule 2, `EveryNoteWriterCallIsAdmittedIntoItsNotesChain`.** Every bound call to a `NoteWriters` method, or to an `ExclusiveCreators` method that carries the `AdmittedCreators` flag, is a site. The containing type is tested as in rule 1: `VaultSession` or any interface it implements. A site that is not admitted is a violation. Violations are answered only by the exception list.
- **Rule 3, `EveryReloadOfATabFromDiskIsAdmittedOrAsksTheChain`.** A site is a bound call to `WorkspaceTabViewModel.ReplaceItem`, `ReplaceItemWithReadText`, `ReloadKeepingCaretLine`, `ReloadKeepingQueuedSave` or `RebaselineAfterPropertyWrite` made from outside `WorkspaceTabViewModel`.
