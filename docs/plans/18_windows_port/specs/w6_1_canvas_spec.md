## 1. Architecture on Windows — the shape every PR shares

```
apps/slate-windows/src/SlateWindows/Canvas/
  CanvasDocumentViewModel.cs      PR A   one per open path (registry on the workspace — the W4-6 BaseDocument pattern);
                                         owns the FFI handle, LoadState, published outline/table/scene/warnings,
                                         CanvasSelection, undo/redo stacks (PR E), filter (PR C), viewport (PR D)
  CanvasSelection.cs              PR A   { Selected: string?, Marked: HashSet<string>, ActiveSurface } — the ONLY selection state;
                                         surfaces bind, never copy
  CanvasSurfaceView.xaml(.cs)     PR A   tab body: header (surface switcher, filter field PR C, warnings/degraded/empty/error
                                         states), the three projections (visibility-gated: exactly one in the UIA tree),
                                         Where-am-I panel (PR C), mode HUD (PR F)
  CanvasOutlineView.cs            PR A   tree projection (TreeView peer)
  CanvasTableView.cs              PR B   AccessibleDataGrid configuration
  CanvasRendererView.cs           PR D   visual projection (custom FrameworkElement + per-card AutomationPeers, windowed)
  CanvasNavigator.cs              PR C   the command layer (next/prev/enter/exit/follow/trace/where-am-I/surface switching)
  CanvasModeController.cs         PR C   M1–M7 machine (test mode lands here; move/resize/connect arrive in PR F)
  CanvasAnnouncer.cs              PR A   thin relay: builds canonical A11yEvents (PR 0a vocabulary), applies the
                                         coalescing policy, posts through AccessibilityNotificationDispatcher — NO text
  CanvasMutationFunnel.cs         PR E   the ONE canvas_apply call site: admission → apply → refresh → undo push → announce
  CanvasCardEditorSheet.xaml      PR E   in-window sheet hosting the real AvalonEdit session on a scratch DocumentBuffer
  CanvasPickers/*.xaml            PR E/F card picker, color/group/connection/direction pickers, vault-file picker, marks list (PR G)
```

Rules that bind every PR (each is a contract row in `docs/plans/34_canvas_contracts.md`, §5.1):

- **R-A One funnel.** Every mutation is `CanvasMutationFunnel.Apply(CanvasAction)`; no other code calls `canvas_apply`. Bulk = one `CanvasAction`, one write, one undo entry, one announcement. Mode-transient geometry (PR F) is the one carved exception (t4 pipeline): the UI holds hypothetical rects, queries `canvas_check_overlap` per step, commits one action on Return, discards on Esc with no backend call.
- **R-B One selection.** `CanvasSelection` lives on the document; panes showing the same canvas share it (mac R8); marks clear when the last tab for the path closes; arrows move `Selected`, never mutate `Marked`.
- **R-C No host prose.** Every audible string is a canonical `A11yEvent` rendered by `a11y_render` (PR 0a). `CanvasAnnouncer.cs` is a relay + coalescer; a source census (the `A11yCorpusCensus`/residue pattern) asserts zero `HostComposed` posts under `Canvas/`. Static UI labels (column headers, button text, empty-state copy) are the mac label inventory verbatim (§W-C label class, recorded in the contracts doc).
- **R-D No re-derivation.** Reading order, containment, adjacency, titles, color names, placement, relative descriptions, auto-sides, bounds, ids, filter matches, trace paths — all consumed from core (PR 0b closes the gaps). The only geometry C# computes is viewport/screen transforms and the mode-transient nudge arithmetic (`rect + step`, min-size clamp from core's constant) — pinned in the audit register (§2).
- **R-E Commands are table rows.** Every verb is a `ChordTable` row (`Reg(...)`, section `CommandSection.Canvas`; `slate.file.newCanvas` in `File`), resolved in `SlateCommandRegistrar.BuildResolvers()`, reachable from the palette (drift test 1), and — where a menu item exists — backed (drift test 2) with the accelerator from the table (drift test 3). Chords are delivered at the declared `ChordScope` (new `ChordScope.Canvas`; typing keys and arrows per R2 only while a canvas projection has keyboard focus). Global-string chords needing imperative delivery (`Window_PreviewKeyDown`) are allow-listed in `ImperativeGlobalRows` with the reason.
- **R-F Modal admission.** Sheets/pickers are `ModalSurface` members (`ModalSurfaces.cs`; `CS8509` is promoted to error so the `IsOpen` arm is mandatory), pass the #1118 chord admission (`SheetChordAdmissionTests`), and are in-window sheets, never `Popup` (W4-5 D-1).
- **R-G Announcements route through the dispatcher** (`AccessibilityNotificationDispatcher.Post`), priority from the event; coalescing policy = mac's (navigation/filter classes 200 ms latest-wins; errors flush pending and post `High`) — W7-2 owns the dispatcher's general coalescing parity; the canvas class keys are pinned in the contracts doc.
- **R-H Tokens only.** Fills/borders/strokes/text come from the W1-1 token set (`ThemeManager.RequiredSlateBrushKeys`) plus the canvas-specific keys PR D adds to `Themes/Slate.Light.xaml`/`Slate.Dark.xaml`/`Slate.Contrast.xaml`; dark/light pairs are APCA-gated in `ThemeTokenContrastTests`; Contrast themes bind to dynamic `SystemColors` pairs, never APCA-gated (decision 11).
- **R-I "C# may contain" (decision 4) for canvas:** view models, UIA peers, the mode-controller and selection state machines, viewport math, WPF marshalling, the undo/redo *stack* (core supplies names + inverses), coalescing timers, pickers' list filtering UI. Nothing else.

## 4. Per-PR specs

Each PR section lists: **Goal · Consumes · Builds · Behavior pinned · Tests · Evidence/acceptance · Hand-off.** "Contracts" means the numbered rows the PR adds to `34_canvas_contracts.md` *before* its round 1 (§5.1).

### PR 0a — Canvas announcer vocabulary → core (Rust + uniffi + mac + censuses)

**Goal.** Every canvas announcement becomes a typed `A11yEvent` with its template, priority, and verbosity policy in `crates/slate-core/src/a11y.rs`; mac `CanvasAnnouncer` shrinks to a relay + coalescer; the residue census count drops; `corpus.json` gains the canvas family; §W-D becomes provable for canvas. **Copy rule: shipped mac strings move verbatim** (the a11y.rs doctrine) — this PR does not redesign wording; t0 §1 is the reference for what the strings are.

**Consumes.** `CanvasAnnouncer.swift` (`CanvasEvent` cases, `phrase(_:)` `:156–213`, `whereAmIText` `:135`, builders `createdText`/`relativePhrase`/`undidText`/`redidText`), the prose sites listed in §2 row A, `CanvasAnnouncerTests.swift` (the grammar matrix — becomes the Rust golden), `MilestoneTIntegrationTests.testAnnouncementGrammarConformsPerVerbosity`.

**Builds.**
1. `CanvasVerbosity { Terse, Standard, Verbose }` (core enum + uniffi mirror). Verbosity is a **parameter on the events that vary by it**, not global state (hosts persist the pref; core stays pure).
2. One `A11yEvent` variant per family — enumerate from the mac `CanvasEvent` enum + every `HostComposed` post under `Canvas/` and `AppState+Canvas*.swift`; **no free-text variant**. Minimum set (names indicative; parameters are the core payload types already in the session records): `CanvasMovedTo{verbosity, kind_label, title, ordinal_n, total_m, container, connection_count, color_name, marked}` · `CanvasGroupEntered{label, count}` · `CanvasGroupLeft{label}` · `CanvasConnectionTraversed{direction, kind_label, title, label}` · `CanvasCreated{kind_label, relative: RelativeDesc}` · `CanvasConnected{from_title, to_title, label}` · `CanvasMovedIntoGroup{label}` / `CanvasRemovedFromGroup` · `CanvasDeleted{count_or_title, undo_chord}` (the destructive family carries the hint at standard+ — **verbosity parameter**) · `CanvasColorSet{title, color_name}` · `CanvasRenamedGroup` · `CanvasMarkToggled{marked, count}` · `CanvasBulk{verb, count, undo_chord}` · `CanvasModeEntered{mode, title}` (M1 text names the exits) · `CanvasModeCommitted{mode, detail}` · `CanvasModeCancelled{mode}` · `CanvasModeRejected{active_mode}` (M7) · `CanvasMoveRelative{descs}` (move-mode coalesced position) · `CanvasOverlapOnset{titles}` / `CanvasOverlapCleared` · `CanvasResizeClamped` · `CanvasFilterCount{matched, total}` / `CanvasFilterCleared{total}` · `CanvasZoom{percent}` · `CanvasUndid{name}` / `CanvasRedid{name}` · `CanvasUndoMenuTitle{name}` (label, not speech — see §2 G) · `CanvasWhereAmI{…all where_am_i fields…, marked, mode, filter}` (always verbose-grade) · `CanvasLoadedDegraded{skipped}` (t0 §5) · `CanvasSaveConflict` · `CanvasFileNotFound{title}` · `CanvasEmptyOnboarding` (the actionable empty-state line) · `CanvasTracePathEnd{visited}`. The PR's contracts doc lists the final enumeration with the mac site each one replaces.
3. **The first chord-bearing templates.** `a11y.rs:34–36` records "no current template carries a chord". The undo hint ("— ⌘Z to undo") and M1's exit phrasing ("Return to place, Escape to cancel") need per-platform chord text. Mechanism (decision 12: chords are host-table-owned): the event carries the **display chord string** as a parameter (`undo_chord: String`) supplied by the host from its chord table (mac `"⌘Z"`, Windows `"Ctrl+Z"`); `a11y.rs` module doc updated; the §W-D census normalizes the chord parameter (it is the one recorded platform difference). Return/Escape key names are literal in the template (identical on both platforms).
4. **Four-place rule** (the W0.5-3 lesson): `a11y.rs` variants + `tests/fixtures/a11y/corpus.json` (regenerate with `SLATE_REGENERATE_FIXTURES=1 cargo test -p slate-core a11y`) + `crates/slate-uniffi/src/lib.rs` mirror + the **two** census mirrors (`apps/slate-mac/Tests/SlateMacTests/A11yCorpusCensusTests.swift`, `apps/slate-windows/tests/SlateWindows.Tests/Censuses/A11yCorpusCensus.cs`).
5. **Mac consumes:** `CanvasAnnouncer.phrase` and the prose sites are replaced by event construction + `a11yRender`; the duplicated preset-name dictionaries and the outline's direction phrases are deleted; `CanvasAnnouncerTests` grammar assertions move to Rust (`a11y` tests, table-driven over verbosity × event) and the Swift tests keep only coalescing/flush/`testNoDirectAnnouncementsUnderCanvas`. `A11yResidueCensusTests.pinnedResidueSites` drops by the canvas count (record old→new).

**Behavior pinned.** Strings byte-identical to the mac test expectations; verbosity matrix per t0 §1.2; Where-am-I always verbose-grade; destructive hint at standard+ only; coalescing stays host (timing), class keys documented in the Rust doc-comment so both hosts copy one list.

**Tests.** Rust: corpus round-trip; per-event verbosity table; priority table (errors/conflicts `High`, navigation `Medium`). Mac: existing canvas suites green unchanged (behavior census); residue count pinned. Windows: `A11yCorpusCensus` mirror extended (it fails by design until the mirror is updated).

**Evidence.** Corpus diff reviewed string-by-string against `CanvasAnnouncerTests` expectations; mac suite green; both census mirrors green in CI.

**Hand-off.** The event list + the chord-parameter convention, cited by PR A's `CanvasAnnouncer.cs`.

### PR 0b — Canvas structural queries, constants, ids, filter → core (Rust + uniffi + mac)

**Goal.** Close §2 rows B–E, F(ordering), H, K, L, M with pure core queries over the existing `CanvasModel`, exposed on `VaultSession` through the handle-based API; mac consumes each and deletes its Swift copy.
