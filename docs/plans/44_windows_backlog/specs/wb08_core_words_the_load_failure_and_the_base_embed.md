# WB-8 — Core words the failure: a tab that cannot load speaks `NoteOpenFailed`, and Ctrl+E titles a `.base` embed as a base

Depends on: nothing (WB-8 is alone in its wave on core's `a11y.rs` corpus, §6). Parallel with: WB-7, WB-9. ## Goal

A note whose load fails today puts the binding's `VaultException.Message`
("@message=…" with field tokens) into the tab's `Status` and `LoadFailure`,
so a screen-reader user hears a diagnostic dump; and Ctrl+E on
`![[Projects.base]]` titles the popover "Embedded note: Projects.base"
while the reading view's card for the same embed says "Embedded base:
Projects". After this chunk both are core's words: a new
`A11yEvent::NoteOpenFailed { name, detail }` renders the load failure (its
detail through `vault_error_detail`), `VaultErrorDetailCensus` guards the
site so a `.Message` read cannot return, and a core free function
`embed_target_kind` classifies the resolved target so the popover, its UIA
name, the embeds leaf and the announcement all read "Embedded base: {name}".

## Design

**Core (`slate-core`).**

- New `A11yEvent::NoteOpenFailed { name: String, detail: String }` beside
  `NoteSaveBlocked` (`a11y.rs:902`). Render: "Could not open {name}:
  {detail}" with `lead_then_sentence`'s closing-period rule, and "Could not
  open {name}." when `detail` is blank (the `NoteSaveBlocked` shape,
  `:2148-2155`). Priority High (`:1870` list). Corpus rows after
  `NoteSaveBlocked`'s (`:4340-4344`): `{ name: "notes.md", detail: "invalid
  UTF-8" }` and `{ name: "notes.md", detail: "" }`; golden pairs beside
  `:7010`. `name` is the file name, as `NoteSaveBlocked.filename` is — the
  host passes `Path.GetFileName(Path)`, not the vault path the current
  status shows.
- New free fn `pub fn embed_target_kind(target_path: &str) -> EmbedTargetKind`
  with `pub enum EmbedTargetKind { Note, Base }`, in `a11y.rs` beside
  `resolved_embed_title` (`:3340`), using `classify_path`'s lower-cased
  extension rule (move or re-export the extension rule so the two cannot
  drift; `session.rs:12588` stays the scanner's). `Base` iff the extension
  is `base`. Never an `EmbedResolution` variant.
- FFI (`slate-uniffi/src/lib.rs`): the `A11yEvent` mirror arm (`:9164`
  region) and its `From` arm (`:11041` region); `#[uniffi::export] pub fn
  embed_target_kind(target_path: String) -> EmbedTargetKind` beside
  `resolved_embed_title` (`:11387`); a `crosses_the_ffi` fact for each
  (the pattern at `:14480`).
